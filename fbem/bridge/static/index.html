📖 Hướng dẫn sử dụng Telegram Bot

1. Đăng bài: Gửi trực tiếp file Video (.mp4) hoặc Ảnh kèm Caption vào Telegram Bot. Bot sẽ hiện nút bấm chọn Fanpage để đăng ngay.

2. Lệnh /status: Kiểm tra xem có bao nhiêu Chrome Profile đang online.

3. Lệnh /pages: Xem danh sách các Fanpage đang quản lý.

4. Lệnh /history: Xem 5 bài đăng mới nhất kèm Link bài viết Facebook.
